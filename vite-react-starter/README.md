# Vite + React Starter

Vite 6, React 19, TypeScript. A small toolkit of hooks and components that are easy to copy into any project.

| Hooks | Components | Helpers |
|---|---|---|
| `useDebounce` | `Reveal` (scroll reveal, reduced-motion safe) | `cn` |
| `useLocalStorage` (safe on blocked storage) | `Accordion` (accessible) | `formatUsPhone` |
| `useMediaQuery` | | `slugify` (unit-tested) |
| `useInView`, `useCopyToClipboard` | | |

```bash
npm install
npm run dev      # start
npm test         # vitest
npm run build    # typecheck + build
```
